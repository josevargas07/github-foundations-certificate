
# GitHub Foundations

**GitHub Foundations | Learning Portfolio**

This repository contains my practical exercises and notes from the **GitHub Foundations** learning path. It documents my experience learning Git, GitHub, version control, collaboration workflows, GitHub Copilot, Codespaces, and repository security.

The exercises are organized into six folders, each covering a different topic and containing the corresponding practice materials.

## About This Repository

The purpose of this repository is to demonstrate my understanding of GitHub fundamentals and document my progress through hands-on exercises.

Throughout this learning path, I practiced managing repositories, tracking code changes, collaborating through GitHub, and exploring developer tools that support modern software development.

## Skills Acquired

Through these exercises, I developed practical knowledge in:

- **Git & Version Control:** Tracking changes, creating commits, managing branches, and merging code.
- **GitHub Collaboration:** Working with repositories, Issues, and Pull Requests.
- **GitHub Copilot:** Using AI to generate code, identify bugs, suggest improvements, and assist with development.
- **GitHub Codespaces:** Working in cloud-based development environments using Visual Studio Code.
- **Code Security:** Understanding CodeQL alerts and basic code scanning workflows.
- **Markdown Documentation:** Creating organized and readable project documentation.
